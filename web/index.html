    Drop in an idea. Two top models plan it, merge their plans, and a team builds it.

    1. Idea You type it and talk it through.
    2. Analyze Opus and GPT each study it.
    3. Plan Each writes a full plan.
    4. Cross review They review each other.
    5. Merge Best parts become one final plan.
    6. Approve You say go.
    7. Build Smaller agents do each task, check their own work, then a big model reviews it.
    8. Final review A big model checks the whole thing.
